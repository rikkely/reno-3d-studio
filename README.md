# reno-3d-studio

一个从 5 m × 4 m 客厅起步的浏览器 3D 装修编辑器。坐标以米为单位，Y 轴向上，地面位于 XZ 平面。

## 第一阶段

- 使用 React、TypeScript、React Three Fiber 和 Drei 搭建可旋转、缩放的场景。
- 先用简单几何体验证家具拖动、0.1 m 网格吸附、0.15 m 墙面吸附与碰撞反馈，再接入经过尺寸和授权检查的 GLB。
- 用 JSON 和 localStorage 保存布局与材质选择；暂不接入账号、云端 API 或 AI。

## 启动与体验

使用 Node.js 22.12+，在仓库根目录执行 `npm ci`、`npm run dev`，打开终端打印的本地地址（浏览器需要支持 WebGL 2）。

拖空白处旋转、滚轮缩放。拖沙发或茶几移动，靠墙时家具边缘贴齐房间边界。重叠时轮廓变红，松手恢复到拖动前的位置。底部可切换沙发布料颜色和地板材质，刷新同一地址会恢复已保存的布局。

当前场景以两面矮墙展示，另外两侧开放以方便观察；四侧均限制摆放。家具暂用固定尺寸、朝向和比例的几何模型。真实 GLB 加载、墙面编辑与 Spring Boot 服务不在本次起步版中。
